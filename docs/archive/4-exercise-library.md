## 한눈에 보기

프로그램 단위는 **요일**이다. 선수는 사이트 홈에서 '오늘 할 일'을 바로 본다. 운동은 아래 라이브러리에서 주차·포지션·근력 수준·통증 단계에 맞춰 골라 넣는다.

- 월 (여자부 시간): 워밍업 → 점프 → 하체 근력. 공 터치는 각자 자율.
- 화: 맨몸 상체·코어 30–40분. 팀 필수, 점프 없음.
- 수·금 (정규 훈련): 워밍업은 팀 방식대로, 끝난 뒤 쿨다운 10분. 기술·전술은 주장이 맡는다.
- 목 (여자부 시간): 워밍업 → 상체 파워 → 근력 → 물구나무·코어.
- 토: 맨몸 하체·균형 30–40분. 팀 필수, 점프 없음. 일: 완전 휴식.

통증이 있는 선수에게는 부위별(어깨·발목·손목·손가락·무릎·허리) **통증 단계**(1 높음 · 2 중간 · 3 낮음 · 4 복귀)에 맞는 재활 운동이 붙는다. 체중 대비 근력은 **인바디** 체중으로 계산한다.

라이브러리는 운동마다 목적, 주차별 처방, 쉬운·어려운 버전, 근거를 함께 적었다. 근거가 약한 항목은 약하다고 표시했다. 그리고 근거 대신 실무 기준으로 정한 숫자는 따로 표시했다.

## 주간 요일 구조

주차는 그대로 두고 각 주를 월~일 7일로 펼친다. 점프와 무거운 하체는 월요일에 둔다. 화요일은 다리를 쉬게 하는 상체 맨몸 날이라 수요일 정규 훈련까지 다리는 48시간을 쉰다. 목요일은 다음 날 정규 훈련이 있어 점프는 포고만 남기고 상체 파워·근력을 채운다. 토요일은 월요일 웨이트 전이라 점프 없는 맨몸 하체를 RIR 3으로 한다.

| 요일 | 1주차 10/26– (측정·적응) | 2주차 11/2– (발달) | 3주차 11/9– (발달·최고 강도) | 4주차 11/16– (감량·대회) |
|---|---|---|---|---|
| 월 | 측정 + 가벼운 점프(1단계) + 동작 연습 · 착지 약 50 | 점프 1–2단계 + 하체 근력 · 착지 약 80 | 점프 2–3단계 + 하체 근력 (무게 ↑) · 착지 약 90 | 재측정 + 점프·근력 절반 (무게 유지) · 착지 약 25 |
| 화 | 맨몸 상체·코어 (2세트) | 맨몸 상체·코어 | 맨몸 상체·코어 | 맨몸 상체·코어 (2세트) |
| 수 | 정규 훈련 + 쿨다운 | 정규 훈련 + 쿨다운 | 정규 훈련 + 쿨다운 | 정규 훈련 (점프 드릴 짧게) + 쿨다운 |
| 목 | 상체 파워·근력·코어 (2세트, 가볍게) | 상체 파워·근력·코어 | 상체 파워·근력·코어 (무게 ↑) | 활성화 30분 |
| 금 | 정규 훈련 + 쿨다운 | 정규 훈련 + 쿨다운 | 정규 훈련 + 쿨다운 | 가벼운 정규 훈련 + 일찍 자기 |
| 토 | 맨몸 하체·균형 (2세트) | 맨몸 하체·균형 | 맨몸 하체·균형 (노르딕 2×5) | 서울대배 1일차 (조별리그 2경기) |
| 일 | 완전 휴식 | 완전 휴식 | 완전 휴식 | 서울대배 2일차 (최대 4경기) |

- 점프 '단계'는 점프 라이브러리의 강도 단계(1 낮음 · 2 중간 · 3 높음)다. 통증 단계와는 다르다.
- 착지 수는 월요일 점프 블록만 센 값이다 (목요일 포고 20회, 정규 훈련 점프는 따로).
- 화·토 맨몸은 팀 필수 세션이다. 피로가 남으면 세트를 줄이고, 주간 부하가 전주의 2배를 넘으면 관리자가 화·토를 줄인다.

## 워밍업(월·목) · 훈련 후 기록(수·금)

워밍업 15분은 각자 진행하는 월·목 웨이트 날과 대회 주 목요일 활성화에만 한다. 수·금 정규 훈련과 대회 날은 팀이 정한 워밍업을 그대로 쓰고, 끝난 뒤 쿨다운 10분만 프로그램에 넣는다. 예외는 무릎 통증 1단계 선수의 훈련 전 등척성(레그 익스텐션 45초 × 5)이다. 쿨다운은 회복을 빠르게 한다는 근거가 약해서 부하 기록과 통증 확인 시간으로 쓴다.

10/23 변경: 수·금 프로그램은 '정규 훈련'과 훈련 후 통증 체크·세션 RPE 기록만 남기고, 아래 쿨다운 표는 참고용으로만 둔다. 웨이트 경험은 초보자(처음, 고블릿·덤벨 RDL) · 중급자(기구 가능, 1주차 빈 바부터, RIR 3 유지) · 숙련자(프리웨이트 자세 앎) 3단계로 나누고, 발목을 다친 적 있는 선수는 월·토에 '발목 재발 예방'(외번 밴드·한 발 균형·공 받기·한 발 홉)을 한다.

**워밍업 15분** (월·목 웨이트 시작 전)

| 순서 | 내용 | 시간 |
|---|---|---|
| 1 | 조깅, 사이드 셔플, 카리오카, 스킵 | 3분 |
| 2 | 회전 런지, 옆 런지, 다리 스윙 (정적 스트레칭을 넣는다면 근육당 30초 이내) | 3분 |
| 3 | 한 발 서기 30초 (좌·우) → 한 발 홉 착지 고정 5회 (좌·우). 발목 염좌 이력자는 1분 추가 | 2분 |
| 4 | 스쿼트 점프 착지 고정 5회: 무릎은 발끝 방향, 착지 소리 작게 | 2분 |
| 5 | 밴드 외회전 2×10, 밴드 벌리기 10, 엎드려 Y·T 각 8, 오픈북 흉추 회전 좌·우 5 | 4분 |
| 6 | 어프로치 점프 3회 (70% → 90%) | 1분 |

- 근거: 균형·착지·근력을 섞은 워밍업은 하지 부상 39%, 발목 염좌 50%를 줄였다 ([Hübscher 요약](https://sponet.de/sponet/Record/4029530?lng=en)). 핸드볼 어깨 프로그램은 어깨 문제를 28% 줄였다 ([Andersson 2017](https://bjsm.bmj.com/content/51/14/1073)). 배구 선수 대상 어깨 워밍업(11+S)은 8주 동안 상체 동적 안정성을 조금 높였다 ([2021 RCT](https://doaj.org/article/d9a877c4f30c4c1fb52513389ad73767)).
- 정적 스트레칭은 근육당 60초 미만이면 수행 저하가 약 −1.1%로 작았고, 60초 이상이면 −4.6%였다. 뒤에 동적 운동을 이어 하면 영향은 무시할 만했다 ([Behm 2016](https://pure.northampton.ac.uk/en/publications/acute-effects-of-muscle-stretching-on-physical-performance-range-/)). 그래서 넣더라도 짧게 한다.

**쿨다운 10분** (수·금 정규 훈련 끝난 뒤)

| 순서 | 내용 | 시간 |
|---|---|---|
| 1 | 가볍게 걷기·조깅으로 심박 내리기 | 3분 |
| 2 | 종아리, 엉덩이 굴곡근, 햄스트링, 어깨 뒤쪽 가벼운 스트레칭 (부위당 30초) | 4분 |
| 3 | 아픈 곳 체크 (3 이상이면 기록에 부위와 함께) | 1분 |
| 4 | 30분 안에 사이트에 세션 RPE 기록 | 2분 |

- 근거: 2018년 리뷰는 능동적 쿨다운이 다음 날 수행이나 근육통 같은 회복 지표를 대부분 개선하지 못했다고 정리했다 ([Van Hooren & Peake 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5999142/)). 쿨다운의 가치는 회복 가속이 아니라 '마무리 루틴'과 '기록 습관'에 있다.
- 세션 RPE는 훈련이 끝나고 조금 지난 뒤 묻는 것이 일반적인 방식이다. 그래서 쿨다운 끝에 기록하게 한다.

## 월·목: 웨이트 날 진행 순서

월·목은 여자부 시간에 웨이트장에서 진행한다. 공 터치는 각자 원하는 만큼 자율로 하고, 프로그램에는 넣지 않는다.

1. 워밍업 15분
2. 파워 블록 (월: 점프 · 목: 포고·메디신볼·박수 푸시업) — 몸이 지치기 전에
3. 주 근력 운동 (세트 사이 충분히 휴식)
4. 보조 근력 운동
5. 재활 운동 (통증 단계가 있는 선수만)
6. 물구나무·코어 (목)

## 하체 근력 라이브러리 (월요일 중심)

양발 근력(스쿼트)과 한 발 근력(스플릿 스쿼트)을 둘 다 넣는다. 한 발 훈련은 한 발 점프를, 양발 훈련은 양발 근력을 더 잘 키웠다 ([일측 vs 양측 메타분석, 2021](https://lida.sport-iat.de/ta/Record/4076571)). 배구는 블록·공격(양발)과 슬라이드·이동(한 발)을 모두 쓴다.

| 운동 | 목적 | 처방 (2주차 / 3주차 / 감량) | 쉬운 ← → 어려운 | 근거 |
|---|---|---|---|---|
| 덤벨 점프 스쿼트 (양손 각 체중 5–10%) | 가벼운 부하로 빠르게 힘 내기 (파워) | 3×4 / 3×4 / — (스쿼트 전에) | 맨몸 스쿼트 점프 ← → 무게 ↑ | 실무 관행. 입문자·상대 근력 < 0.8은 제외, 3주차 상대 근력 > 1.2면 컨트라스트로 바꿈 |
| 백스쿼트 | 양발 최대 근력, 점프 기반 | 4×5 RIR 3 / 4×4 RIR 2 / 2×3 같은 무게 | 고블릿 스쿼트 ← → 프런트 스쿼트 | 근력+점프 병행이 점프 단독보다 유리 ([농구 메타분석](https://lida.sport-iat.de/ta/Record/4084159?lng=en)) |
| 루마니안 데드리프트 | 햄스트링·엉덩이, 착지 시 몸통 고정 | 3×6 RIR 3 / 3×5 RIR 2 / 2×5 | 덤벨 RDL ← → 바벨 RDL | 실무 관행 |
| 불가리안 스플릿 스쿼트 | 한 발 근력, 좌우 차이 | 3×6 / 3×6 무게 ↑ / 1×6 | 맨몸 스플릿 스쿼트 ← → 덤벨 | 한 발 점프 향상 효과크기 0.89 (위 메타분석) |
| 덤벨 스텝업 (벤치 높이) | 한 발 밀기, 착지 통제 | 3×6 / 3×6 / — | 낮은 박스 ← → 무게 ↑ | 위 메타분석 (일측 훈련) |
| 바벨 힙 쓰러스트 | 엉덩이 신전, 짧은 가속·방향 전환 | 3×8 RIR 2 / 3×6 / 2×6 | 글루트 브리지 ← → 한 발 힙 쓰러스트 | 스쿼트보다 단거리 스프린트·방향 전환 향상이 컸음 ([2019 RCT](https://doaj.org/article/7b62de8f66194d32b376f6e3d3136851)) |
| 한 발 카프레이즈 | 발목 강성, 착지 흡수 | 3×12 / 3×10 무게 ↑ / 1×12 | 양발 ← → 덤벨 들고 한 발 | 실무 관행 |
| 햄스트링 컬 머신 | 무릎 굴곡근 | 2×8 / 2×8 / — | — | 실무 관행 |
| 노르딕 햄스트링 (토요일 맨몸, 파트너가 발목 고정) | 햄스트링 편심 근력 | 토 2×4 / 2×5 / — (입문자 제외) | 밴드 보조 ← → 맨몸 | 포함 프로그램이 부상을 약 51% 줄였다는 메타분석 ([van Dyk 2019](https://search.pedro.org.au/search-results/record-detail/56553)), 단 재분석에서 효과가 불확실하다는 지적 ([재평가](https://www.physio-network.com/research-reviews/thigh/why-methods-matter-in-a-meta-analysis-a-reappraisal-showed-inconclusive-injury-preventive-effect-of-nordic-hamstring-exercise/)) |

**강도 정하는 법**: 1RM을 재지 않고 RIR(세트 끝에 더 할 수 있었던 횟수)로 정한다. RIR 기반 체감 척도는 바 속도와 강하게 반비례했다(경험자 r=−0.88, 초보 r=−0.77) ([Zourdos 2016](https://openrepository.aut.ac.nz/items/efef3b25-6701-4fb5-bb82-55fcd2a26027/full)). 웨이트 경험이 적으면 RIR 판단이 서툴 수 있어 첫 2주는 RIR 3을 기준으로 한다 (실무 기준).

**근력 수준별 선택 (실무 기준, 근거 아님)**: 10/26 측정의 스쿼트 5회 무게 ÷ 체중으로 나눈다.

| 상대 근력 | 스쿼트 종류 | 점프 3단계 허용 |
|---|---|---|
| 웨이트 경험 없음 또는 < 0.8 | 고블릿 스쿼트 | 아니오 |
| 0.8–1.2 | 백스쿼트 | 3주차부터 일부 |
| > 1.2 | 백스쿼트 또는 프런트 스쿼트 | 예 |

### 훈련 변인 세부 설계

같은 운동이라도 '얼마나 빨리, 얼마나 쉬고, 어떤 순서로' 하느냐에 따라 효과가 달라진다. 처방표의 세트×횟수 뒤에는 아래 변인이 깔려 있다.

| 변인 | 처방 | 근거 |
|---|---|---|
| 의도한 속도 | 모든 근력 운동의 올라가는 구간은 '최대한 빠르게' (무게가 무거워 실제로 느려도 의도는 최대). 내려가는 구간은 2–3초로 통제 | 같은 무게를 최대 속도로 든 그룹이 일부러 절반 속도로 든 그룹보다 6주 뒤 1RM이 두 배 가까이 올랐다(+18.2% vs +9.7%) ([González-Badillo 2014](https://rio.upo.es/entities/publication/c94a5051-591d-43bf-99e8-8c11ce0ca9d3/full)) |
| 세트 간 휴식 | 주 근력 운동(스쿼트·RDL) 3분, 보조 운동 90초, 점프 60–90초 | 최대 근력과 파워는 1분보다 3–5분 휴식에서 더 잘 올랐다 ([de Salles 2009](https://read.qxmd.com/read/19691365/rest-interval-between-sets-in-strength-training)) |
| 운동 순서 | 점프 → 양발 주 근력 → 한 발 운동 → 보조 → 코어 | 점프와 고강도 동작은 지치기 전 (NSCA 지침, 1단계 문서) |
| 세트 종료 기준 | 목표 RIR에 도달하거나, 바 속도가 눈에 띄게 느려지거나, 자세가 무너지면 그 세트 종료 | RIR과 바 속도는 강하게 반비례 ([Zourdos 2016](https://openrepository.aut.ac.nz/items/efef3b25-6701-4fb5-bb82-55fcd2a26027/full)) |
| 복합(컨트라스트) 훈련 | 상대 근력 > 1.2인 선수만, 3주차에: 백스쿼트 3회 → 90초 쉬고 CMJ 3회 묶음 × 3 | 무거운 스쿼트 뒤 점프 향상은 상대 근력이 높은 선수에게서 더 컸다 ([Kinesiology](https://hrcak.srce.hr/en/195351)) |
| 주간 증가폭 | 근력 운동은 주당 무게 2.5–5kg, 점프는 주당 착지 수 20% 이내 증가 | 실무 기준 (점프 수 급증과 무릎 통증 근거는 1단계 문서) |

## 점프·플라이오메트릭 라이브러리 (월요일, 3단계)

점프는 강도에 따라 세 단계로 나누고, 주차와 선수 상태에 따라 단계를 연다. 배구 선수 대상 RCT 메타분석에서 플라이오는 주 2회 이하, 2,000회 미만의 적은 양으로도 점프 높이를 올렸다(효과크기 0.82) ([Ramirez-Campillo 2020](https://lida.sport-iat.de/ta/Record/4064643?lng=en)). 우리는 정규 훈련 점프가 이미 많으므로 월요일 한 번, 착지 수를 1주 약 50 → 2주 약 80 → 3주 약 90 → 4주 약 25로 잡는다.

| 단계 | 운동 | 처방 (주차별) | 큐 (코칭 포인트) | 열리는 조건 |
|---|---|---|---|---|
| 1 낮음 | 포고 점프 | 2×10 (4주차 1×10) | 발목만 튕기듯, 무릎 거의 고정 | 항상 |
| 1 | 스쿼트 점프 착지 고정 | 1–2주차 2×5 | 착지 후 2초 멈춤, 무릎은 발끝 방향 | 항상 |
| 1 | 스냅다운 (팔 휘두르며 착지 자세로 떨어지기) | 1주차 2×5 | 소리 없이, 엉덩이 뒤로 | 항상 |
| 1 | 옆으로 한 발 바운드 → 착지 고정 | 1주차 2×3 (좌우) | 바깥발로 2초 멈춤 | 항상 |
| 2 중간 | CMJ 최대 노력 (팔 스윙) | 3×4 → 3×3 → 2×3 | 매 회 최고 높이, 세트 사이 60–90초 | 2주차 + 한 발 서기 30초 통과 |
| 2 | 연속 제자리멀리뛰기 (3연속, 센다이 방식) | 3세트 → 3세트 → 2세트 | 착지하자마자 다음, 무릎 안 모이게 | 같음 |
| 2 | 연속 옆 바운드 (좌우 번갈아) | 2–3주차 2×6 | 멀리, 바깥발로 밀기 | 같음 |
| 2 | 연속 허들 점프 (낮은 콘·가방 5개) | 2×5 → 3×5 | 지면 접촉 짧게, 무릎 끌어올리기 | 같음 |
| 2 | 한 발 앞으로 홉 → 착지 고정 | 2×2 → 2×3 (좌우) | 무릎이 안으로 모이지 않게 | 같음 |
| 3 높음 | 포지션별 어프로치 점프 | 3주차 3×3, 4주차 2×2 | MB 슬라이드 후 블록, OP·OH 공격 스텝, S 점프 토스 테이크오프 | 3주차 + 상대 근력 ≥ 0.8 |
| 3 | 드롭 점프 (30cm 벤치) | 3주차 2×4 | 떨어지자마자 최대한 빨리·높이 | 3주차 + 상대 근력 > 1.2 + 무릎 통증 단계 없음 |

포지션: 세터는 CMJ·멀리뛰기를 1세트씩 줄인다. 리베로는 CMJ 대신 옆 바운드 착지 고정을 하고, 멀리뛰기·허들·드롭을 빼고, 포지션 점프 대신 5-10-5를 한다. 통증 단계: 무릎 1–3단계·발목 1단계는 점프 블록을 쉬고, 발목 2단계는 1단계 점프만 한다.

- **착지 교육**: 착지 기술을 지시·피드백하는 훈련은 착지 시 무릎 굽힘 각도를 중간 크기로 늘렸다(g=0.77). 효과는 1–3회 세션 만에도 나타났다 ([Bathe 2023 메타분석](https://bmjopensem.bmj.com/content/9/2/e001508.full.pdf)). 그래서 1주차는 1단계와 착지 피드백에 집중한다.
- **드롭 점프 높이**: 반응 근력 지수로 개인별 최적 높이(10–40cm)를 정한 그룹이 30cm 고정 그룹보다 CMJ가 더 올랐다(+16.7% vs +7.4%). 다만 저자들도 고정 높이를 실용적 대안으로 인정했다 ([축구 선수 7주 연구](https://pure.hartpury.ac.uk/en/publications/optimal-reactive-strength-index-is-it-an-accurate-variable-to-opt/)). 우리는 측정 장비가 없으므로 30cm 고정, 3주차 일부 선수로 한정한다.
- **멈춤 신호**: 착지 소리가 커지거나, 무릎이 안으로 모이거나, 높이가 눈에 띄게 떨어지면 그 운동을 끝낸다.

## 상체·어깨 라이브러리 (목요일 중심)

목요일 상체 운동의 목적은 공격 속도를 직접 올리는 것보다 **어깨를 버티게 하는 것**이다. 스페인 1부 여자팀을 한 시즌 추적한 연구에서 벤치·풀오버 근력과 메디신볼 던지기 기록은 올랐지만, 점프 스파이크 속도는 오르지 않았다 ([배구 시즌 추적 연구](https://hrcak.srce.hr/160776)). 공격 속도는 실제 공격 연습(주장 영역)에서 키우고, 피지컬은 어깨 안정과 당기는 힘을 맡는다.

| 운동 | 목적 | 처방 (2주차 / 3주차) | 쉬운 ← → 어려운 | 근거 |
|---|---|---|---|---|
| 메디신볼 오버헤드 슬램 · 옆으로 던지기 | 전신 파워 연결 | 3×5 (1–3주차, 매번 최대 속도) | 2kg ← → 4kg | 스파이크 속도 전이는 확인 안 됨 (위 시즌 연구) |
| 박수 푸시업 (플라이오 푸시업) | 상체 미는 파워 | 3×5 (2–3주차) | 무릎 대고 ← → 박수 | 실무 관행. 입문자, 어깨 1–2단계, 손목 통증 단계가 있으면 제외 |
| 턱걸이 | 당기는 힘, 견갑 하강 | 4×3–6 / 4×최대 −1회 | 점프 후 3–5초 내려오기 ← → 중량 | 실무 관행 |
| 덤벨 벤치프레스 | 미는 힘 (어깨 앞뒤 균형) | 3×8 RIR 2 / 3×6 무게 ↑ | 푸시업 ← → 바벨 | 실무 관행 |
| 한 팔 덤벨 로우 | 등·견갑 후인 | 3×8 | — | 실무 관행 |
| 옆으로 누워 덤벨 외회전 | 회전근개 외회전 근력 (스파이크 감속) | 2×15 | 밴드 ← → 덤벨 | 외회전 약화는 던지기 종목 어깨 문제 위험요인 (Andersson 2017) |
| 엎드려 Y·T·W 들기 | 하부 승모근, 견갑 후인 | 각 2×8 | 맨손 ← → 0.5–1kg | 같은 근거 |
| 견갑 푸시업 · 슬리퍼 스트레치 · 밴드 90/90 외회전 | 전거근 · 내회전 가동범위 · 공격 자세 외회전 | 워밍업·화요일 맨몸·어깨 재활에서 | — | 같은 근거 |

- 핸드볼 OSTRC 어깨 프로그램은 내회전 가동범위, 외회전 근력, 견갑 근력, 흉추 가동성을 묶어 주 3회 워밍업으로 했고, 어깨 문제를 28% 줄였다. 위 운동 중 외회전·Y·T·W·슬리퍼 스트레치가 그 구성 요소다.
- 어깨 통증 1–2단계: 메디신볼·박수 푸시업·머리 위 동작을 빼고, 통증 없는 범위의 외회전·견갑 운동만 한다.

## 코어·체간 라이브러리 (목요일 + 선택일)

코어 운동은 짧게, 보조로 둔다. 24개 연구를 검토한 리뷰는 코어 안정성 훈련만으로 얻는 경기력 이득이 '미미하다'고 결론 내렸다 ([Reed 2012](https://sponet.de/sponet/Record/4027189?lng=en)). 그래서 목요일 10–15분과 화·토 맨몸 날 일부로 두고, 몸통을 '버티는' 운동 위주로 고른다. 팀이 약하다고 느끼는 물구나무는 어깨 안정과 몸통 고정을 함께 쓰므로 여기에 단계별로 넣는다.

| 운동 | 버티는 방향 | 처방 | 쉬운 ← → 어려운 |
|---|---|---|---|
| 데드버그 | 허리 꺾임 버티기 | 2×8 (좌우) | 다리만 ← → 팔다리 동시 |
| 할로우 홀드 | 허리 꺾임 버티기 | 3×20초 | 무릎 굽혀 ← → 팔다리 펴서 |
| 사이드 플랭크 | 옆으로 무너짐 버티기 | 2×30초 (좌우) | 무릎 대고 ← → 위쪽 다리 들기 |
| 덤벨 한 손 들고 걷기 | 옆으로 무너짐 버티기 | 2×20m (좌우) | 가볍게 ← → 무겁게 |
| 코펜하겐 플랭크 (안쪽 허벅지) | 옆으로 무너짐 버티기 + 내전근 | 목 2×20초 → 3×25초 (좌우), 토 짧게 | 무릎 대고 ← → 발목 대고 |
| 버드독 | 회전 버티기 | 2×8 (좌우) | — |
| 밴드 팔로프 프레스 | 회전 버티기 | 2×10 (좌우) | 밴드 약하게 ← → 강하게 |
| 행잉 니레이즈 (턱걸이 바) | 골반 말기 | 2×8 | 무릎 ← → 다리 펴서 |
| 물구나무 1: 파이크 버티기 | 어깨 위 체중 지지 | 3×30초 | 발을 벤치에 |
| 물구나무 2: 벽 걸어 올라가기 | 같음 | 3–5회 | — |
| 물구나무 3: 벽 물구나무 버티기 | 같음 | 3×20–40초 | — |
| 물구나무 4: 벽 어깨 터치 → 킥업 → 물구나무 걷기 5m (센다이 방식) | 같음 | 3×4 터치 | — |

- 물구나무 단계는 10/26 측정에서 정하고, 한 단계를 3×30초 안정적으로 하면 다음 단계로 간다 (실무 기준).
- 세터는 머리 위 안정이 직접 쓰이므로 물구나무를 매 목요일 빠짐없이 한다. 어깨 통증 1–2단계면 물구나무 대신 견갑 운동을 한다.
- 코펜하겐 플랭크를 넣는 이유: 코펜하겐 근력 프로그램을 한 축구팀은 시즌 중 사타구니 문제가 41% 적었다 (13.5% vs 21.3%) ([Harøy 2019](https://search.pedro.org.au/search-results/record-detail/55148)). 배구의 낮은 수비 자세·옆 이동에도 같은 근육을 쓴다.

### 코어 지구력 테스트 (변화 확인용)

코어가 강해지는지는 McGill의 체간 지구력 테스트 3종으로 본다. 운동선수에게서도 쓰이는 검사다 ([체간 지구력 테스트 신뢰도 연구](https://sponet.de/sponet/Record/4013602)). 긴 플랭크 하나보다 옆·뒤·앞을 따로 재서 약한 쪽을 찾는다.

| 테스트 | 방법 | 끝나는 순간 |
|---|---|---|
| 사이드 플랭크 왼·오른 | 팔꿈치와 발 옆면으로 버티기 | 엉덩이가 내려갈 때 |
| 풀 플랭크 | 팔꿈치와 발끝으로 몸을 일자로 | 허리가 처지거나 엉덩이가 올라갈 때 |

등·앞쪽 버티기(비에링-소렌센·60° 굴곡)는 팀에서 재기 어려워 풀 플랭크 하나로 합쳤다 (10/23).

- 언제: 10/26 측정날, 2주차 화요일(맨몸 날 끝에), 4주차 월요일. 선수가 사이트 기록 탭에 직접 남긴다.
- 보는 법: 네 숫자의 합계와 첫 기록 대비 변화. 측정 오차가 커서 5초 안팎의 차이는 변화로 보지 않는다 (실무 기준). 사이드 좌우 차이가 크면 약한 쪽을 1세트 더 한다.
- 물구나무 단계와 함께 홈 화면 '내 지표'에 표시된다.

## 통증 단계별 재활 (부상·통증)

통증이 있는 부위는 **지금 아픈 정도**로 4단계 중 하나를 고르고, 그 단계의 재활 운동이 요일 프로그램에 붙는다. 단계는 어깨 임상지침에서 운동 강도를 정하는 '자극 민감도(높음·중간·낮음)'에 복귀 단계를 더한 것이다 ([CSM 2014, Kelley 지침 인용](https://www.orthopt.org/uploads/content_files/files/2014%20CSM%20ICF_based_CPG_Presentation.pdf)). 이 프로그램은 진단이나 치료가 아니다.

**통증 단계 기준**

| 단계 | 기준 (운동할 때 · 다음 날 아침 · 쉴 때) | 하는 운동 |
|---|---|---|
| 1 높음 | 쉬거나 밤에도 아픔, 또는 운동 중·다음 날 아침 7점 이상 | 통증 없는 범위 가동성·등척성, 그 부위 부하 줄이기 |
| 2 중간 | 운동 중 또는 다음 날 아침 4–6점 (운동 땐 괜찮았는데 다음 날 꽤 아픈 경우 포함) | 등척성 + 가벼운 근력 |
| 3 낮음 | 운동 중·다음 날 아침 모두 1–3점 | 무거운 근력·파워·점프 (무릎은 드롭·실전 점프 제외) |
| 4 복귀 | 통증 없음 (관리자가 지정) | 배구 동작을 단계적으로 |

두 시점을 따로 보는 이유: 통증 모니터링 모델은 운동 중 통증뿐 아니라 '다음 날 아침에 평소로 돌아왔는지'를 부하 조절 기준으로 쓴다 ([Silbernagel 2007 요약](https://physicaltherapyfirst.com/blog/continued-sports-activity-using-a-pain-monitoring-model-during-rehabilitation-in-patients-with-achilles-tendinopathy/)). 운동 땐 안 아프다가 다음 날 아픈 것은 그 날 부하가 넘쳤다는 신호라서 2단계로 본다.

**진행 규칙**

- 통증 모니터링 규칙: 운동 중 통증 5 이하, 다음 날 아침 평소대로, 주마다 늘지 않기. 지키면 그대로, 어기면 양을 줄이거나 한 단계 내린다. 이 규칙으로 아파도 계속 운동한 그룹은 6주 쉬게 한 그룹보다 나쁜 결과가 없었다. 허용 통증 수치는 연구마다 다르고, 5는 가장 흔한 기준이다 ([통증 허용 기준 근거 정리](https://www.uantwerpen.be/en/research-groups/movant/blog/provokepain/)).
- 통증 체크: 아픈 곳이 있으면 사이트 '통증 체크'에 부위, 운동할 때, 오늘 아침, 쉴 때·밤에도 아픈지를 남긴다. 각 시점은 0 없음 / 1–3 살짝 / 4–6 꽤 아픔 / 7–10 많이 아픔 중에서 고른다. 나아지면 0으로 남기면 단계가 풀린다.
- 어느 단계가 적용되나: 최근 14일 안의 통증 체크가 가입 때 낸 통증보다 우선한다. 관리자가 고른 단계가 있어도 최근 체크가 더 나쁘면 그 단계가 먼저 적용되고, 관리자 홈 '확인할 선수'에 뜬다.
- 다음 단계: 규칙을 1–2주 지키고 운동 중·다음 날 통증이 다음 구간으로 내려가면 올린다.
- 먼저 의료진: 붓기·불안정감·밤 통증·저림이 있거나, 같은 부위 통증이 2주 넘게 이어지면 운동보다 진료가 먼저다. 다친 직후 1–3일은 아픈 동작을 피해 보호한다.
- 다른 부위는 계속: 어깨가 아파도 하체 프로그램은 그대로, 무릎이 아파도 상체·코어는 그대로 한다.

### 어깨: 와순 파열(SLAP 등)·회전근개 문제

와순 파열은 주변 근육(회전근개, 견갑 주변근)으로 관절을 받쳐 주는 보존적 재활로 버티는 경우가 많다. 보존 치료를 한 와순 파열 환자 중 약 절반은 수술 없이 지냈다. 다만 같은 수준의 머리 위 종목으로 돌아간 비율은 66%였다 ([Edwards 2010](https://orthopaedicprinciples.com/2010/08/slap-nonoperative-rx)). 수술을 받은 선수는 이 표가 아니라 집도의의 재활 프로토콜을 따른다.

| 단계 | 목표 | 운동 (처방) | 다음 단계 조건 |
|---|---|---|---|
| 1 높음 · 쉬거나 밤에도 아프고 팔이 끝까지 안 올라감 | 뒤쪽 어깨 유연성, 견갑 위치 | 슬리퍼 스트레치 · 크로스바디 스트레치 각 30초 × 3–5 / 견갑 모으고 내리기 등척 10초 × 10 / 벽 밀기 외회전 등척 10초 × 5 | 일상 통증 2/10 이하, 머리 위로 팔 올릴 때 통증 없음 |
| 2 중간 · 팔을 끝까지 올리거나 운동하면 아픔 | 회전근개·견갑 근지구력 → 근력 | 옆으로 누워 덤벨 외회전 3×15 / 엎드려 Y·T·W 각 2×10 / 견갑 푸시업 플러스 2×12 / 밴드 로우 3×12 / 밴드 외회전 (팔 옆 0° → 통증 없으면 90/90) 3×12 | 외회전 운동 무게가 반대쪽과 비슷, 운동 중 통증 3/10 이하 |
| 3 낮음 · 스파이크·서브처럼 세게 할 때만 아픔 | 빠른 외회전 제어 | 밴드 90/90 빠른 외회전 3×10 / 메디신볼 가슴 패스 → 가벼운 오버헤드 던지기 3×8 / 무릎 대고 플라이오 푸시업 2×6 | 빠른 동작에서 통증·빠지는 느낌 없음 |
| 4 복귀 · 안 아픔, 공격 복귀 중 | 공격·서브 복귀 | 서서 벽에 때리기 20회 → 서브 20회 → 점프 스파이크 10회, 세션마다 개수 늘리기 (주장과 협의) | 정규 훈련 공격량을 이틀 연속 문제없이 소화 |

- 뒤쪽 어깨 스트레칭(슬리퍼·크로스바디)은 30초 × 3–5회로 내회전 가동범위를 늘렸고, 견갑 안정화 운동을 함께 했을 때 개선이 더 컸다 ([스트레칭 리뷰](https://doaj.org/article/58747417202949b6924a7d8bf7f0e941)).
- 외회전 약화·내회전 제한·견갑 운동 이상은 머리 위 종목 어깨 문제의 위험요인이고, 이를 묶은 프로그램이 어깨 문제를 28% 줄였다 ([Andersson 2017](https://bjsm.bmj.com/content/51/14/1073)).
- 1–2단계 동안 피할 것: 팔을 끝까지 뒤로 젖힌 자세의 고강도 동작(공격 백스윙 끝), 무거운 이두근 컬, 통증을 참는 스트레칭 (일반적인 재활 원칙).

### 발목: 염좌 후·자주 삐는 발목

발목 염좌는 배구에서 가장 흔한 급성 부상이고, 가장 큰 위험요인은 같은 발목의 이전 염좌다. 그래서 '다 나았다'고 느낀 뒤가 실제 처방의 시작이다. 근거상 핵심은 두 가지다. **균형 훈련**과, 다친 뒤 1년간 **경기·훈련 중 보조기 착용**이다.

| 단계 | 목표 | 운동 (처방) | 다음 단계 조건 |
|---|---|---|---|
| 1 높음 · 걸을 때도 아프고 붓어 있음 | 붓기 뒤 발목 각도 회복 | 무릎 벽 대기 (발끝-벽 거리 늘리기) 2×10 / 발목 알파벳 그리기 2회 / 양발 카프레이즈 2×15 | 걸을 때 통증 없음, 한 발로 10초 서기 가능 |
| 2 중간 · 걷기는 괜찮고 뛰거나 운동하면 아픔 | 비골근·종아리 근력, 한 발 균형 | 밴드 바깥쪽 밀기(외번) 3×15 / 한 발 카프레이즈 3×12 / 한 발 서기 30초 × 3 → 눈 감고 → 쿠션 위 / 한 발 서서 공 받기 2×10 | 눈 감고 한 발 30초, 한 발 카프레이즈 좌우 횟수 비슷 |
| 3 낮음 · 점프·방향 전환 때만 아픔 | 착지 흡수, 옆 방향 제어 | 양발 → 한 발 홉 착지 고정 3×5 / 라인 좌우 홉 2×10초 / 옆으로 한 발 바운드 착지 고정 3×4 | 한 발 홉 거리 좌우 차이 10% 이내 (실무 기준) |
| 4 복귀 · 안 아픔 | 네트 앞 착지 | 블록 스텝 → 블록 점프 착지 3×5 / 어프로치 점프 3×3 / 정규 훈련 단계적 복귀 | 통증·불안정감 없이 정규 훈련 이틀 연속 |

- 만성 발목 불안정 연구를 모은 리뷰에서 자가 보고 기능을 가장 일관되게 올린 것은 균형 훈련이었다 ([Kosik 2017](https://bjsm.bmj.com/content/51/2/105)).
- 배구 116팀 연구에서 밸런스보드 프로그램은 염좌 이력이 있는 선수의 재발을 줄였다 ([Verhagen 2004](https://pubmed.ncbi.nlm.nih.gov/15310562/)).
- 염좌를 겪은 운동선수 384명 연구에서 1년간 반경성 보조기를 찬 그룹의 재발은 15%, 8주 신경근 훈련만 한 그룹은 27%였다(상대위험 0.53) ([Janssen 2014](https://search.pedro.org.au/search-results/record-detail/38348)). 그래서 이 처방은 **보조기 + 균형 훈련**을 함께 권한다.
- 무릎 부상 이력이 있으면 쿠션·보드 같은 불안정한 면 대신 바닥 균형으로만 한다 (같은 Verhagen 연구).

### 손목·손가락: 블로킹 손가락 부상, 손목 통증

배구 상지 부상 중 손가락이 가장 흔하고, 손목이 그다음이다. 미국 청소년 응급실 자료에서 상지 부상의 43%가 손가락, 23%가 손목이었다 ([2024 상지 부상 역학](https://doaj.org/article/e0c0490f61e6479bbe9f517d63d6a3ae)). 덴마크 연구도 손·손가락 염좌를 가장 흔한 부상으로 꼽고, 블로킹과 오버 토스 기술을 예방 지점으로 들었다 ([1995 BJSM](https://bjsm.bmj.com/content/29/3/200)). 손목·손가락 강화 운동 자체의 근거는 약하므로, 아래는 실무 처방으로 쓴다. 우리 팀은 물구나무를 넣었기 때문에 손목 준비 운동이 특히 필요하다.

**손가락 염좌 (공에 손가락이 꺾임)**

- 먼저 의료진: 손가락이 휘어 보이거나, 끝마디를 스스로 펴지 못하거나, 붓기가 심하면 진료가 먼저다 (골절·힘줄 손상 가능).
- 복귀 중: 옆 손가락과 묶는 버디 테이핑을 하고 훈련한다.

| 단계 | 운동 (프로그램) | 다음 단계 조건 |
|---|---|---|
| 1 높음 · 가만히 있어도 아프고 붓어 있음 | 손가락 힘줄 미끄러짐 운동(주먹 모양 5종) 각 10회 × 하루 3번, 통증 없는 범위 / 옆 손가락과 같이 테이핑 | 주먹을 끝까지 쥐고 펼 수 있음 |
| 2 중간 · 주먹 쥐거나 힘줄 때 아픔 | 고무줄 손가락 벌리기 3×15 / 수건·공 쥐기 3×10 (5초 유지) | 쥐는 힘 좌우 비슷 |
| 3 낮음 · 공 받을 때만 아픔 | 벽 오버 토스 (가볍게) 3×20 / 블로킹 손 모양 → 가벼운 공 막기 2×10 | 공 받아도 통증 3 이하 |
| 4 복귀 · 안 아픔 | 정규 훈련 토스·블로킹 단계적 참여 (테이핑 유지) | — |

**손목 통증 (디그·토스·블로킹, 물구나무 준비)**

| 단계 | 운동 (프로그램) | 다음 단계 조건 |
|---|---|---|
| 1 높음 · 가만히 있어도 아픔 | 손목 원 그리기 · 손바닥 스트레칭 각 30초 / 네발 자세에서 앞뒤로 체중 싣기 30초 × 3 | 손 짚어도 통증 3 이하 |
| 2 중간 · 손을 짚거나 운동하면 아픔 | 덤벨 손목 굽히기·펴기 각 2×15 (1–2kg) / 덤벨 돌리기 2×12 / 엄지·새끼 방향 들기 각 2×12 / 원판 꼬집어 들기·수건 짜기 30초 × 3 | 손목 운동 무게가 반대쪽과 비슷 |
| 3 낮음 · 푸시업·물구나무처럼 체중 실을 때만 아픔 | 플랭크 → 푸시업 3×30초 → 3×8 / 물구나무 1단계(파이크 버티기) 3×30초 | 푸시업·파이크에서 통증 없음 |
| 4 복귀 · 안 아픔 | 토스·디그 정상 참여, 물구나무 단계 복귀 | — |

- 손목 통증 1–2단계면 물구나무 대신 견갑 운동, 3단계면 파이크 버티기(1단계)까지만 하고, 주먹 쥐고 하는 푸시업이나 손목 보호대를 써 손목 꺾임을 줄인다 (실무 기준).

### 무릎: 과도한 점프로 인한 앞무릎 통증 (점퍼스니)

무릎뼈 바로 아래가 점프·착지 때 아프고, 앉았다 일어날 때 뻐근하면 슬개건병증(점퍼스니)일 가능성이 크다. 핵심은 **쉬게 하는 것이 아니라 힘줄이 견디는 부하를 단계적으로 올리는 것**이다. 점진적 힘줄 부하 운동(PTLE)은 24주 뒤 무릎 기능 점수(VISA-P)를 편심 운동보다 9점 더 올렸고, 첫 보존 치료로 권장됐다 ([Breda 2021](https://search.pedro.org.au/search-results/record-detail/63178)). 아래 4단계는 그 연구의 단계 구성(등척성 → 등장성 → 에너지 저장 → 종목 복귀)을 따른다.

무릎의 통증 단계 설명은 점퍼스니를 통증 시점으로 나누는 Blazina 분류(운동 후에만 아픔 → 운동 중·후 아프지만 뛸 수 있음 → 오래 아프고 경기력 저하)에 맞췄다 ([점퍼스니 4단계 분류](https://en.wikipedia.org/wiki/Patellar_tendinitis)). 단계별 운동 구성은 [Delaware PT 슬개건병증 가이드](https://bpb-us-w2.wpmucdn.com/sites.udel.edu/dist/c/3448/files/2016/01/Patellar-Tendinopathy.pdf)와 같다 (등척성 45초 × 5 → 3–4세트 15RM→6RM, 3초 올리고 3초 내리기).

| 단계 | 목표 | 운동 (처방) | 다음 단계 조건 |
|---|---|---|---|
| 1 높음 · 운동 중·후 오래 아프고 경기력이 떨어짐 (등척성) | 통증 낮추고 힘줄에 부하 시작 | 레그 익스텐션 무릎 약 60°에서 강하게 버티기 45초 × 5, 세트 간 2분. 매일 가능, 정규 훈련 전에도 | 한 발 스쿼트 시 통증 3/10 이하 |
| 2 중간 · 운동 중·후에 아프지만 뛸 수는 있음 (무겁고 느린 근력) | 힘줄 강성·근력 | 레그 익스텐션·스쿼트·한 발 레그프레스: 3초 올리고 3초 내리기, 15회 → 주마다 무게 올려 8–6회, 3–4세트, 주 3회 | 체중 1배 이상 스쿼트 6회를 통증 3/10 이하로 |
| 3 낮음 · 운동 끝난 뒤에만 아픔 (에너지 저장·점프) | 빠른 신장-단축 견디기 | 포고 → 스쿼트 점프 → 연속 멀리뛰기 → 한 발 홉, 주 2–3회, 각 단계 착지 수를 점차 늘림 | 점프 다음 날 아침 통증이 평소보다 늘지 않음 |
| 4 복귀 · 안 아픔 | 배구 점프량 회복 | 어프로치 점프 → 블록 점프 → 정규 훈련 점프 드릴 단계적 참여 | 정규 훈련 이틀 연속 소화, 다음 날 통증 증가 없음 |

- **통증 기준**: 위 진행 규칙(운동 중 5 이하, 다음 날 아침 평소대로)을 따른다. 점프 다음 날 아침 통증이 늘면 점프 양부터 줄인다.
- **점프 수부터 줄이기**: 훈련 시간과 경기 세트가 늘수록 점퍼스니 위험이 컸다. 그래서 1–2단계 동안은 처방 점프를 빼고, 정규 훈련 점프 드릴 참여도 관리자와 주장이 조정한다 (1단계 문서 근거).
- **시즌 중 계속 뛰어야 할 때**: 25° 경사판 한 발 디클라인 스쿼트가 배구 선수의 12개월 뒤 기능 개선에 유리했다 ([Young 2005](https://search.pedro.org.au/search-results/record-detail/11203)). 다만 통증을 참고 하는 방식이라 1단계 등척성으로 통증을 먼저 낮춘 뒤 쓴다.
- 2단계 근력 운동은 통증이 있는 쪽만이 아니라 양쪽 모두 한다.

### 허리: 서브·공격 반복으로 인한 허리 통증

배구의 허리 통증은 대부분 허리를 뒤로 젖힐 때(신전) 아프다. 고교 배구 선수 70명을 무작위로 나눈 연구에서, 흉추 가동성·체간 안정화·스트레칭을 워밍업에 넣은 팀의 허리 통증 발생은 4주 동안 8.8%였고 대조 팀은 33.3%였다. 통증 사례의 약 70%가 허리 신전 때 나타났다 ([고교](https://search.pedro.org.au/search-results/record-detail/71845)[ 배구 RCT](https://search.pedro.org.au/search-results/record-detail/71845)). 그래서 '허리 대신 등(흉추)과 엉덩이가 움직이게' 하는 것을 목표로 한다.

| 단계 | 운동 (프로그램) | 다음 단계 조건 |
|---|---|---|
| 1 높음 · 쉬어도 아프고 움직이기 힘듦 | 오픈북 흉추 회전 좌우 8회 × 2 / 폼롤러 위 흉추 신전 5회 × 2 (허리는 바닥에) / 하프 닐링 엉덩이 굴곡근 스트레칭 30초 × 2 (좌우) | 일상 통증 2 이하 |
| 2 중간 · 숙이거나 운동하면 아픔 | 데드버그 2×8 · 할로우 홀드 3×20초 / 글루트 브리지 → 힙 쓰러스트 3×10 / 버드독 2×8 (좌우) | 운동 중 통증 3 이하 |
| 3 낮음 · 무거운 무게 들 때만 아픔 | RDL 가볍게 → 평소 무게, 고블릿 → 백스쿼트 (주마다 단계적으로) | 무게를 올려도 다음 날 괜찮음 |
| 4 복귀 · 안 아픔 | 서브·공격 정상 참여 | — |

- 허리 통증 1–3단계면 RDL을 가볍게 하고, 1–2단계면, 바벨을 등에 지는 스쿼트 대신 고블릿 스쿼트로 바꾼다.
- 다리 저림·힘 빠짐, 밤에 심해지는 통증, 2주 이상 계속되는 통증은 진료가 먼저다 (피로 골절인 척추분리증 가능성).
- 서브·공격 자세에서 허리를 과하게 젖히는 습관은 기술 문제라 주장과 함께 본다.

## 리베로·수비 이동 드릴

리베로의 '반사신경'은 몸(첫 스텝, 낮은 자세)과 읽기(상대 공격 예측)로 나뉜다. 피지컬 쪽은 방향 전환 능력을 키우는 드릴을 맡는다. 66개 연구 메타분석에서 근력·스피드·파워·민첩성 훈련은 모두 방향 전환 능력을 올렸고, 민첩성 훈련의 효과가 가장 컸다(효과크기 1.05) ([방향 전환 메타분석](https://lida.sport-iat.de/ta/Record/4085256)).

| 드릴 | 방법 | 처방 | 언제 |
|---|---|---|---|
| 신호 반응 스타트 | 수비 자세 → 파트너 손짓 방향(좌·우·앞)으로 2–3걸음 출발 | 6–8회 × 2 | 목 (워밍업 뒤) |
| 셔플 → 앞 다이빙 준비 자세 | 옆 셔플 3m → 낮게 앞으로 한 걸음 + 손 뻗기 | 좌우 각 5회 | 목 |
| 5-10-5 (프로 에질리티) | 5m 옆 → 10m 반대 → 5m 복귀, 낮은 무게중심 | 4회, 회당 완전 휴식 | 월 (점프 블록 대신 일부) |
| 수비 자세 월싯 | 무릎 약 90°, 팔은 리시브 자세 | 3×30초 | 목 |
| 옆으로 한 발 바운드 착지 고정 | 바깥발 착지 2초 | 3×4 (좌우) | 월 (리베로 점프 블록) |
| 롤링·다이빙 착지 연습 | 매트에서 낮은 높이부터 | 5–10분 | 1년차 위주, 주장과 협의 |

- 근력·파워 훈련도 방향 전환을 올리므로, 리베로도 하체 근력 블록은 그대로 하고 점프 블록만 줄인다.
- 공격 읽기 훈련은 실제 공격수를 보고 반응하는 드릴이라 주장과 협의해 정규 훈련에 넣는다. 불빛 반응 같은 범용 반응 훈련은 넣지 않는다 (1단계 문서의 근거).

## 화·토: 맨몸 트레이닝 · 일: 휴식

화·토는 장비 없이 하는 맨몸 트레이닝 30–40분을 팀 필수 세션으로 한다. 점프는 넣지 않는다 (주간 점프 수가 갑자기 늘지 않게). 화요일은 월요일 다리 회복일이라 상체·코어, 토요일은 월요일 웨이트 전이라 하체·균형을 RIR 3으로 한다. 1주차와 4주차는 2세트만 하고, 일요일은 완전히 쉰다.

**화: 맨몸 상체·코어**

| 운동 | 처방 | 큐 |
|---|---|---|
| 푸시업 (무릎 → 일반 → 발 올리고) | 3×최대 −2회 | 몸통 일자, 가슴이 먼저 닿게 |
| 턱걸이 또는 인버티드 로우 (낮은 철봉) | 3×6–8 | 견갑부터 당기기 |
| 파이크 푸시업 → 물구나무 단계 연습 | 3×6 + 5분 | 머리 위로 미는 힘, 세터 필수 |
| 곰 기기 앞뒤 · 게 걷기 | 각 2×10m | 무릎 바닥에서 5cm 띄우기 |
| 할로우 홀드 · 슈퍼맨 | 3×20초 · 2×10 | 허리 뜨지 않게 |
| 가동성: 흉추 회전 · 엉덩이 굴곡근 · 종아리 | 5분 | — |

**토: 맨몸 하체·균형**

| 운동 | 처방 | 큐 |
|---|---|---|
| 워킹 런지 | 3×8 (다리당) | 뒷무릎이 바닥 가까이 |
| 한 발 스쿼트 (벤치에 앉았다 일어나기 → 낮은 박스 → 맨바닥) | 3×5 (다리당) | 5회 가능한 높이로, 무릎은 발끝 방향 |
| 한 발 힙 브리지 | 3×10 (다리당) | 위에서 1초 |
| 노르딕 햄스트링 | 2×4 → 3주차 2×5 | 파트너가 발목 고정, 입문자 제외 |
| 한 발 카프레이즈 (맨몸) | 2×15 (다리당) | — |
| 한 발 서기 → 눈 감고 → 한 발로 공 받기 | 좌우 각 30초 (발목 이력자 1분) | 발목 안정성 |
| 사이드 플랭크 · 코펜하겐 플랭크 (짧게) | 각 2×20초 (좌우) | — |

통증 단계가 있으면 바뀐다: 무릎 1–2단계는 런지·한 발 스쿼트 대신 벽 기대 앉기 4×45초, 어깨 1–2단계나 손목 1–2단계는 파이크 푸시업 대신 견갑 운동.

**수면**: 휴식일에 가장 신경 쓸 것은 운동보다 잠이다.

- 테니스 선수 5명이 5–6주 동안 10시간 수면을 목표로 하자 스프린트 기록과 서브 정확도가 좋아졌다 ([수면 연장 연구](https://aasm.org/study-shows-sleep-extension-improves-athletic-performance-and-mood/)). 표본이 작아 크기를 믿기는 어렵지만 방향은 일관된다.
- 수면 부족과 정신적 피로는 비치발리볼 수비·블로킹 반응시간을 떨어뜨렸다 ([Barbosa 2025](https://public-pages-files-2025.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2025.1537482/text)). 시험 기간과 대회 전날에 특히 중요하다.

## 인바디(체성분) 활용

인바디는 처방을 정하는 '측정 도구'로 쓰고, 목표 자체로 쓰지 않는다. 점프 높이는 체중 대비 힘에 달려 있다. 그래서 인바디의 체중·골격근량·체지방 추세를 점프 측정값과 함께 보고, 근력 처방의 기준(체중 대비 근력)으로 쓴다.

**측정 결과지에서 입력할 항목**

| 항목 | 처방에서 쓰는 곳 |
|---|---|
| 체중 (kg) | 상대 근력 = 스쿼트 5회 무게 ÷ 체중 → 운동 난이도와 점프 3단계 허용 여부 |
| 골격근량 (kg) | 체중 대비 근육 비율 추세. 근력 블록 뒤 근육이 늘었는지 확인 |
| 체지방량 (kg)·체지방률 (%) | CMJ와 함께 추세로 봄. 체중이 늘었는데 CMJ가 그대로면 늘어난 것이 근육인지 확인 |
| 부위별 근육량 (오른다리·왼다리·팔) | 다리 근육량 좌우 차이가 크면 한 발 운동 비중을 늘림 (실무 기준, 보조 지표로만) |
| 측정 조건 체크 | 아래 조건을 지켰는지 함께 기록해 비교 가능한 값만 추세에 씀 |

**정확도와 측정 조건**

- 운동하는 성인 155명에서 인바디 770은 DXA보다 제지방량을 높게, 체지방률을 낮게 쟀다. 그래도 저자들은 같은 방법끼리 비교한다면 사용할 만하다고 봤다 ([Bod Pod·InBody 770·DXA 비교](https://www.journalofexerciseandnutrition.com/index.php/JEN/article/view/44)). 그래서 **같은 기계로 잰 값끼리만** 비교하고, 다른 곳 인바디 값과 섞지 않는다.
- 측정 직전에 물 2L를 마시자 다주파 생체임피던스의 체지방률이 올라갔다 ([수분 섭취 영향 연구](https://lida.sport-iat.de/ta/Record/4085614?lng=en)). 수분 상태가 값을 흔든다.
- **측정 조건 (실무 기준)**: 아침 공복, 화장실 다녀온 뒤, 운동 전(전날 고강도 훈련 피하기), 같은 기계, 가벼운 옷. 측정 간격은 4주 이상으로 하고, 1–2% 안팎의 변화는 오차로 본다.

**쓰지 않을 것**

- 체지방률 순위나 감량 목표를 팀에 공개하지 않는다. 대회 블록 중 체중 감량 처방도 하지 않는다.
- 인바디 결과는 부상 정보처럼 **본인과 관리자만** 본다.

## 프로그램 규칙: 누구에게 무엇을

사이트는 아래 순서로 그날의 프로그램을 만든다. 위에서부터 적용하고, 아래 규칙이 위 규칙을 덮어쓴다(통증 규칙이 가장 우선).

1. **주차 → 점프 단계와 세트 수**: 1주차 1단계, 2주차 1–2단계, 3주차 2–3단계, 4주차 2단계 절반 (무게 유지, 세트·횟수 감소)
2. **포지션 → 점프 종류와 양**
   - MB: 슬라이드 후 블록 점프, 100%
   - OP·OH: 공격 어프로치 점프, 100%
   - S: CMJ·연속 멀리뛰기 1세트씩 감소, 물구나무 필수
   - Li: 수직 점프 대신 옆 바운드·방향 전환 드릴, 점프 착지 수 약 절반
3. **상대 근력 (스쿼트 5회 무게 ÷ 체중) → 운동 난이도**: < 0.8이면 고블릿 스쿼트·3단계 점프 없음, 0.8–1.2면 3주차 어프로치 점프만, > 1.2면 드롭 점프까지 (실무 기준)
4. **측정 → 잠금 해제**: 한 발 서기 30초 실패 시 2·3단계 점프를 잠그고 착지 고정으로 대체. 물구나무 단계에 맞춰 목요일 단계 표시
5. **부상 이력 → 추가**: 발목 염좌 이력은 균형 +1분, 무릎 부상 이력은 불안정 지지면 균형 제외
6. **현재 통증 (가입 정보·세션 기록) → 제한**: 부위별(무릎·어깨·발목·허리·손목·손가락) 통증 점수를 통증 단계로 바꿔(7 이상 1단계, 4–6은 2단계, 3은 3단계) 재활 운동을 붙이고 9번 제한을 적용. 어느 하나라도 ≥ 3이면 '관리자와 상담' 표시
7. **주간 점프 수 → 경고**: 기록된 주간 착지 수가 전주의 2배 이상이면 '주의'만 표시하고 처방은 관리자가 판단

- 3번의 상대 근력 기준과 4번의 30초 기준은 연구에서 정해진 숫자가 아니라 실무 관행이다. 블록이 끝나면 팀 데이터로 다시 맞춘다.
- 6번은 세션 기록의 통증 값으로도 갱신되게 만든다. 지금은 가입 때 입력한 통증만 반영된다.

**추가 규칙 (****통증 단계·인바디·요일****)**

8. 통증 단계: 부위(어깨·발목·손목·손가락·무릎·허리)와 단계(1 높음 · 2 중간 · 3 낮음 · 4 복귀)가 정해지면 그 단계 운동이 월·목에 붙고, 화·토에는 가벼운 단계만 붙는다. 관리자가 고른 단계가 자가 보고 점수보다 우선한다.
9. 단계와 일반 프로그램의 충돌: 무릎 1–3단계·발목 1단계면 점프 블록을 빼고(무릎 3단계는 재활의 점프 단계로 대신), 발목 2단계면 1단계 점프만, 어깨 1–2단계면 메디신볼·박수 푸시업·물구나무를 빼고, 손목 1–2단계면 물구나무 대신 견갑 운동(3단계면 1단계까지), 허리 1–2단계면 고블릿 스쿼트, 무릎 1단계면 정규 훈련 전 등척성.
10. 인바디: 측정 조건을 지킨 최신 인바디 체중으로 상대 근력을 계산한다. 인바디가 없으면 가입 때 적은 체중을 쓴다.
11. 요일: 수·금 정규 훈련과 대회 날은 팀 워밍업을 쓰고 우리 워밍업은 넣지 않는다. 화·토는 점프 없는 맨몸 트레이닝이다.

## 사이트 반영 계획

10/22 기준 반영 현황이다. 체크 안 된 항목이 남은 작업이다.

- [x] '선수별 처방' 화면을 **주차 선택 → 요일 탭(월~일)** 구조로 바꾸고, 오늘 날짜의 요일 탭이 자동으로 열리게 한다
- [x] 각 요일 카드에 그날 블록을 순서대로 표시: 워밍업 → 점프 → 근력 → 보조 → 재활 운동 / 정규 훈련일은 (팀 워밍업·정규 훈련) → 쿨다운
- [x] '워밍업·원칙' 탭을 없애고, 그 내용을 해당 요일 카드 안으로 옮긴다
- [ ] 운동 라이브러리를 데이터 파일로 분리한다 (운동마다 이름, 단계, 큐, 쉬운·어려운 버전, 근거 링크). 운동 이름을 누르면 설명이 펼쳐진다
- [x] 처방 규칙 1–7을 코드로 옮기고, 측정값의 상대 근력을 계산해 반영한다
- [ ] 세션 기록의 통증 값이 3 이상이면 다음 처방에 바로 반영되게 한다
- [x] '이번 주' 팀 화면도 요일 기준으로 '오늘 할 일' 요약을 보여준다

- [x] 부위별 재활 6개(어깨·발목·손목·손가락·무릎·허리)를 데이터로 만들고, 관리자 화면에서 선수별 '부위 + 통증 단계'를 지정·변경할 수 있게 한다
- [ ] 인바디 결과 입력 폼과 측정 조건 체크, 선수별 추세 그래프(체중·골격근량·체지방률·CMJ)를 추가한다. 본인과 관리자만 볼 수 있게 한다
- [x] 볼 감각 드릴은 처방에서 빼고, 월·목 카드에 '공 터치는 자율'로만 표시한다
- [x] 홈 화면(오늘 할 일·이번 주·기록·내 지표, 관리자는 팀 현황), '처방' → '프로그램' 용어
- [x] 통증 단계(1 높음 · 2 중간 · 3 낮음 · 4 복귀)와 가입 때 상태 설명으로 통증 고르기, 손목·손가락 추가
- [x] 화·토 맨몸 트레이닝, 월 점프 확대, 목 파워 블록, 수·금 워밍업 제거
- [ ] 인바디·CMJ 추세 그래프 (지금은 표만)
