# SNUVT — 서울대 배구부 관리

남자부·여자부가 같이 쓰는 배구부 앱이에요.

- 화면: 정적 파일(HTML·JS)
- 로그인·데이터: Supabase (프로젝트 `juhcaodotxspzzzfzrnt`)
- 배포: Vercel. [GitHub `suhyeok3691/SNUVT`](https://github.com/suhyeok3691/SNUVT)의 `main`에 올리면 자동으로 배포돼요.
- 주소: https://snuvt.vercel.app

이 문서 하나에 지금 앱의 구조·데이터·운영을 모았어요(바뀐 내역은 git 기록). DB의 정확한 정의는 `supabase/schema.sql`에 있어요.

| --- | --- |

| 피지컬 | 오늘 · 프로그램 · 기록 |

| 일정 | 다가오는(2주 안 전체 일정: 훈련·자율·교류전·OB전·대회·교내 대회) · 전체 일정(대회·일정 · 교류전 · 교내 대회, 수정·삭제) · 훈련 관리(직책) |
| 대회 | 대회(엔트리 · 세트별 라인업(6인제) / 서브 타순(9인제) · 실시간 기록) · 교류전(세트별 출전 · 실시간 기록) · 교내 대회 · 정산(내역은 모두, 관리는 총무 쪽) |
| 전력분석 | (위 탭 없음) 경기 · 실시간 · 시즌 · 팀별 · 리포트 |
| (메뉴) 관리 | 명단 · 부원(승인·직책) · 리포트 |
| (오른쪽 위) 설정 | 내 정보 · 알림 · 화면 보기(직책별) · 탈퇴 |

**휴대폰 메뉴 = 돌림판 다이얼**: 아래에는 가운데 홈 버튼 하나만 떠 있어요. 짧게 누르면 홈, **길게 누르면(또는 위로 밀면) 작은 원판**(지름 약 230px)이 홈 버튼 위로 떠올라요. 원판 **가운데가 홈**이고, 둘레에 칸(훈련 · 피지컬 · 영상 · 일정 · 대회 · 전력분석, 권한 있으면 관리)이 한 바퀴 고르게 있어요. 처음엔 지금 화면 칸이 위 ▼에 와 있어요. 손가락으로 원판을 **끝없이 돌리고**(시계 방향 = 다음 칸), 칸이 ▼를 지날 때마다 진동 '틱' · 위에 이름.
- 천천히 돌려 놓고 떼면 ▼ 칸에 맞춰 **바로 그 화면으로**(제자리로 돌아가지 않음)
- **휙 튕기면 돌림판처럼 관성으로 계속 돌다** 마찰로 느려져 칸에 맞춰 멈추고 열린 채로 있어요. 도는 원판을 손가락으로 잡으면 멈추고 다시 돌릴 수 있어요. 위 이름(▼ 칸)이나 아무 칸을 누르면 그 칸으로, 가운데를 누르면 홈
- 안 돌리고 떼면 열린 채로. 바깥이나 뒤로 가기로 닫기. 홈 화면에서 홈 버튼을 눌러도 열림
- 원판은 CSS 변수 `--rot` 하나로 돌려서(transform만) 끊기지 않아요. 처음엔 홈 버튼 위에 "길게 눌러 메뉴" 안내, 한 번 쓰면 사라짐(`snuvt-dial`). 넓은 화면(760px 이상)은 위에 7칸 그대로. 코드 `dialBind` · `dialOpen` · `dialMove` · `dialSet` · `dialSpin` · `dialPick`

## 3. 팀과 직책

### 팀
- 가입할 때 남자부·여자부를 골라요. 다른 팀 데이터는 DB 규칙(RLS의 `team scope`)으로 막혀서 보이지도, 고쳐지지도 않아요.
- 팀마다 다른 것:
  - 정규 훈련 요일: 남자부는 1학기 월·목, 2학기 수·금이고 여자부는 반대예요. 시간은 18:00–21:00.
  - 네트 높이: 남자부 243cm, 여자부 224cm
  - 일정·공지·영상·훈련 계획
- 총관리자(`profiles.super`)는 설정에서 남자부·여자부를 오갈 수 있어요.
- 여자부 첫 관리자는 그 사람이 여자부로 가입한 뒤 SQL Editor에서 정해요:
  `update public.profiles set role = 'coach' where email = '이메일' and team_id = 'women';`
  그다음부터는 앱의 관리 → 부원에서 직책을 정하면 돼요.

### 직책 (팀마다)

| 직책 | 할 수 있는 것 | 서버 권한 `private.can(...)` |
| --- | --- | --- |
| 관리자 · 주장 | 전부 | (모두 true) |
| 부주장 | 일정 · 교류전 · 엔트리 · 공지 · 명단 · 영상 · 훈련 관리 · 정산 | schedule · notice · roster · video · attend · money |
| 훈련 담당 | 훈련 계획 · 훈련 관리(정규 훈련 변경 · 자율 훈련 · 불참 확인) | practice · attend |
| 총무 | 공지 · 명단 · 정산 | notice · roster · money |
| 피지컬 담당 | 피지컬 프로그램 편집 · 측정 수정 · 리포트 | training |
| 전력분석 담당 | 전력분석 경기 추가·수정 · 라인업 · RESET · 지운 기록 되살리기, 실시간 기록 | analysis |
| 영상 담당 | 영상 추가·수정 | video |
| 부원 · 군 복무 | 내 운동·기록 · 일정 · 참·불참 투표 · 불참 · 전력분석 입력(내 기록 고치기 · Undo) | — |

- 한 사람이 직책을 여러 개 맡을 수 있어요(`players.titles`, 예: 피지컬 + 영상). 권한은 맡은 직책을 모두 합친 것이고, 화면 보기는 '내 직책 ↔ 부원'이에요.
- 앱의 `STAFF_PERMS`(app.js)와 DB의 `private.can`은 항상 같게 맞춰요.
- 정규 훈련은 참석이 기본이라 '불참'만 누르고, 자율 훈련·대회·교류전은 참·불참 투표를 해요.

### 개인정보 규칙
- 부상·통증·개인 조정은 본인과 관리자(관리자·주장)·피지컬 담당만 봐요.
- 키·몸무게(`player_private`)는 본인과 관리자·피지컬 담당만 봐요. 여자부는 몸무게 "비공개"를 고를 수 있음(가입 정보 · 내 정보): 고르면 몸무게를 아예 저장하지 않고 `player_private.weight_private = true`(RPC `set_weight_private`), 관리자 화면·엑셀엔 "비공개". 전화번호(`player_contacts`)는 본인과 명단 담당만 봐요.
- 체지방 순위나 감량 처방은 만들지 않아요.
- 졸업·탈퇴하면 개인정보를 지우고(`private.wipe_personal`), 이름과 운동 기록만 남겨요.

- **남녀부 바꾸기**: 설정 → 계정 → 팀. 총관리자와 관리자 · 주장(role coach)만 보이고, 서버 `switch_team`도 같은 규칙(다른 부원은 42501). 바꾸면 저장해 둔 화면 자료와 따로 불러온 전력분석 · 실시간 기록 · 대회 라인업(`state.scout` · `live` · `cup`)도 비워서 새 팀 것만 다시 받음
- **명단에 선수 추가**: 대회 엔트리 선정 · 전력분석 Edit Lineup(SNU 쪽) · 실시간 라인업 창(SNU 쪽)에 "+ 명단에 선수 추가"(관리자 · 주장). 이름 · 번호 · 포지션만으로 `players`에 넣음(가입 안 한 부원, 아직 아무도 없는 여자부). 쓰던 칸 값은 그대로 되살리고, 엔트리에서 넣었으면 엔트리에 바로 체크. 같은 번호가 있으면 한 번 묻고 넣음

| 알림 | `push_subs` | 기기별 알림 구독 (운동 기록 저녁 시각 · 공지) |
| 운영 | `client_errors` | 앱 오류 기록 (관리자만 봄, 60일) |
| | `private.trash` · `private.snapshots` | 지운 줄 휴지통(60일) · 매일 스냅샷(15일) — 앱 API로는 안 보임 (5절) |

읽기·쓰기 권한은 표마다 RLS 정책으로 정해 두었어요(`supabase/schema.sql` 6절).
- 기본: 팀원은 읽기, 맡은 직책만 쓰기
- 개인 기록: 본인과 관리자, 그리고 피지컬 담당만

### 백업 · 되살리기
- **휴지통** `private.trash`(tbl · row jsonb · deleted_at · by_user): 팀 데이터 표 38개(아래 스냅샷과 같은 목록)에서 지우는 줄은 지우기 직전에 트리거 `keep_deleted`가 복사, 60일 보관. Undo · RESET · 삭제 · 연쇄 삭제 모두
- **매일 스냅샷** `private.snapshots`(taken_at · tbl · n · data jsonb): `private.take_snapshot()`이 표마다 jsonb로 복사, 15일치. 일본 고교 · 알림 구독은 뺌. 꺼내 보기: `select jsonb_array_elements(data) from private.snapshots where tbl = 'players' order by taken_at desc limit 1;`
- 전력분석은 앱에서 되살림(6-9). 다른 표는 SQL로: `select row from private.trash where tbl = '표' and deleted_at > now() - interval '1 day';` → `insert into public.표 select (jsonb_populate_record(null::public.표, row)).* from private.trash where …`
- **앱 오류 기록** `client_errors`(at · user_id · team_id · view · msg · src · stack · ua · ver): 우리 파일에서 난 오류 · 처리 안 된 Promise 오류만, 같은 오류는 한 번 · 앱을 켤 때마다 5개까지. 확인: `select at, view, msg, src, ver from client_errors order by at desc limit 50;`

## 6. 기능

경기는 아마추어 규칙: **3판 2선승, 1 · 2세트 21점 · 3세트 15점(2점 차)** — 1 · 2세트를 한 팀이 다 이기면 3세트는 안 보이고 "경기 끝". 전력분석 · 실시간 기록 · 대회/교류전 세트 탭이 모두 이 규칙(`court.js`의 `SET_MAX` · `setTarget` · `setWinner`).
- **전력분석은 경기마다 세트 규칙**(`scout_matches.rules` = `{bo, to, pts}`): 세트 방식 "3판 2선승"(대회 기본, 21 · 21 · 15) / "세트 수 자유"(교류전 기본 — 경기 끝 없이 세트가 끝날 때마다 "다음 세트로", 세트 수 제한 없음) · 세트 점수(기본 21). 세트마다 점수가 다르면 기록 화면 "Set N 21점"을 눌러 15 · 21 · 25 · 직접 입력(`pts`, 전력분석 담당 이상). 코드 `ctRules` · `ctTarget` · `ctWinner`. 세트 번호는 DB에서 1~30(`scout_events` · `scout_points`)

## 6-0. 팀 영상
- 재생목록을 펼치면 위에 플레이어(맨 위 영상 = 가장 최근 영상), 아래에 그 재생목록 영상 목록. 재생목록마다 넣는 순서가 달라서(최근 것 위 · 아래) **제목의 날짜**(26.11.19 · 2026.03.12 · 26.5.19 · 10/9)로 최근 날짜 먼저, 같은 날은 제목 마지막 숫자 순(1 → 2 → 3세트), 날짜 없는 제목은 재생목록에서 바로 옆 영상의 날짜(`vidDate` · `vidList`). 누르면 그 영상을 바로 틂(`embed/{영상}?playlist={영상},…` — playlist를 주면 유튜브는 playlist 첫 영상부터 트므로 고른 영상을 맨 앞에). 유튜브 퍼가기 재생목록(videoseries)은 새로 넣은 영상이 한참 늦게 보여서 `yt-latest`가 읽은 목록으로 틂(목록을 못 읽으면 예전처럼 videoseries)
- 새 영상 반영: 영상 화면을 열 때마다(1분 넘었으면) · 앱으로 돌아올 때 다시 받음(`loadYtUpd`). 영상을 보는 중이면 플레이어는 그대로 두고 글자 · 목록만 바꿈

## 6-1. 홈 · 알림
- **오늘 할 것**(부원, 홈 맨 위): 오늘 피지컬(누르면 피지컬 화면) · 오늘 팀 훈련(불참 표시 · 공개된 훈련 계획 ›). 피지컬이 그날 팀 훈련 · 교류전 그 자체면 한 줄만. 둘 다 없으면 안 보임
- **알림 켜기 안내**: 이 기기에서 알림을 안 켠 부원 홈 맨 위에 "알림 켜기 [켜기] [나중에]". 켜기 = 운동 기록(운동 있는 날 기록이 없으면 오후 10시) · 새 공지. 시각은 설정 → 알림에서. "나중에"는 이 기기에서 다시 안 뜸. 아이폰 Safari(설치 전)는 "홈 화면에 추가" 안내
- 피지컬 회복 버전: 어제 세션 RPE 9 이상이면 오늘 웨이트는 회복 버전(`readiness`)
- 숫자 칸을 고른 채로 마우스 휠을 굴리면 칸에서 빠져나와 화면만 스크롤(값이 갑자기 안 바뀜)
- 기기 시계 확인: 탭을 열 때 한 번 서버 시각(`server_now()` RPC, 오간 시간의 가운데로)과 기기 시계를 비교해 5분 넘게 다르면 맨 위에 빨간 안내("이 기기 시계가 N분 빨라요 — 시간 자동 설정 · 시간대 서울"), 다시 맞으면 사라짐. 시계가 틀리면 로그인 토큰이 바로 만료된 걸로 보여 계속 새로 받다가 막히고(429) 로그인이 풀림(`clockCheck`)
- 앱 시작: 이 기기에 저장해 둔 화면 자료(로그인한 사람별)로 먼저 그리고, 뒤에서 새로 받아 조용히 바꿈. 서비스 워커는 버전 붙은 스크립트(`?v=`)는 저장본 먼저, `index.html`은 네트워크 먼저

## 6-2. 휴대폰 동작
- 새로고침해도 보던 안쪽 화면(대회 하나 · 전력분석 경기 · 실시간 기록 경기와 세트)에 그대로(`sessionStorage` `snuvt-nav`, 탭마다)
- 뒤로 가기: 화면을 바꿀 때마다 기록을 쌓아 휴대폰 뒤로 가기(버튼·밀기)가 됨. 순서: 열린 창 닫기 → 안쪽 화면(대회 하나·일본 고교 학교·전력분석 경기) 나가기 → 이전 화면. 아이폰 홈 화면 앱은 왼쪽 끝에서 오른쪽으로 밀면 뒤로 감(직접 만든 동작)
- 전화번호 칸은 숫자만 쳐도 하이픈 자동 (010-1234-5678 · 02-123-4567)

## 6-3. 학사일정 (`terms`, 남녀 함께)
- 학기마다 개강 · 종강(보강 기간 마지막 날). 일정 → 훈련 관리 맨 아래 한 줄("학사일정 2학기 ~12/21 · 1학기 넣기")을 눌러 넣음(일정 담당·관리자)
- 개강 주에 피지컬 흐름(기준 주)이 새로 시작하고, 2학기 종강 다음 날부터 겨울 방학(비시즌)
- 서울대 학사일정 페이지는 자동 수집을 막아 둬서(robots) 자동으로 못 가져옴 → 1년에 한 번 보고 넣기. 이번 학기 종강이나 다음 학기 개강(시작 두 달 전부터)이 비어 있으면 일정 담당 홈 맨 위에 작게 "학사일정 넣기"가 뜸

## 6-4. OB전 · 투표 · 지우기
- OB전: 일정 종류 "OB전". 전원 참이라 투표·불참 없음(경조사는 개별 연락). 그날은 교류전처럼 경기 날
- 투표 버튼 색: 투표(파랑) · 참(초록) · 불참(빨강). 투표 창에서 "투표 취소"로 되돌릴 수 있음
- 참·불참 숫자는 일정·출석 담당과 관리자만 목록에서 봄. 일반 부원은 투표 버튼을 눌러 뜨는 창 아래 명단으로만 봄(불참 사유는 담당만)
- 지우기·취소 버튼은 모두 빨간 테두리 박스, 누르면 한 번 더 확인. 수정 창이 있는 것(일정·교류전·교내 대회·팀·경기·측정·영상·전력분석 경기·훈련 블록·불참·노트·선수)은 삭제를 창 맨 아래 점선 밑에 따로 둠

## 6-5. 다른 팀 훈련 참가 (남자부 ↔ 여자부) — 화면 이름은 "여자부 훈련 참가"(여자부에선 "남자부 훈련 참가")
- 다가오는 일정·달력에 상대 팀 정규 훈련 날이 "여자부 정규 훈련 · 18:00–21:00 [참가]"로 뜸. 누르면 창에서 몇 시부터 몇 시까지(기본은 그 팀 훈련 시간) 남김 → `guest_votes`(start_time·end_time). 다시 누르면 시간 수정·참가 취소
- 상대 팀 날짜 계산: `guest_cal()`(security definer)로 그 팀의 요일 바꿈 · 일정 · 훈련 없는 날 · 바뀐 시간 · 교류전 날짜만 받아 와서 우리와 같은 규칙(`seasonDay`)으로 정규 훈련 날을 구함. 그 팀 교류전·OB전·대회·교내 대회·훈련 없음 날은 안 뜸
- 우리 팀 일정이 먼저: 그날 우리 교류전·대회·교내 대회·OB전·정규 훈련이 있으면 참가가 안 뜨고, 달력도 우리 일정 색으로
- 누가 오는지: 받는 팀의 관리자·주장·부주장·훈련 담당(`can('attend')`)만 `guest_list()`로 봄 → 그 팀 다가오는 일정의 정규 훈련 줄에 "여자부 2 · 이름 포지션 19:00–21:00"
- 달력 색: 참가하기로 한 날은 분홍 테두리("여자부 훈련 참가")

## 6-6. 교류전 투표 대상
- 교류전 추가·수정 창의 "투표 대상": 전체(기본, 군 복무 빼고 모두) / 지정(선수를 골라 그 사람만). 수정할 때는 "주전 N명"·"엔트리 N명" 버튼으로 한 번에 고름 → `friendlies.vote_to`(uuid[], 비면 전체)
- 서버도 막음: `event_votes`의 restrictive 정책(`private.fr_vote_ok`)이 지정에서 빠진 사람의 교류전 투표 넣기·바꾸기를 거절
- 지정에서 빠진 사람: 투표 버튼 대신 "대상 아님", 내 투표에 안 뜸, 그날 프로그램은 교류전이 아니라 정규 훈련 없는 날처럼(골라서 하는 날)
- 참·불참·미응답 숫자와 명단, 오늘 불참자도 지정한 사람 기준

## 6-7. 대회 세트별 라인업 · 서브 타순
- **6인제 대회**: "세트별 라인업" — 세트마다 로테이션 시작 위치 I~VI(I = 1번 자리 서브, 라인업 용지 순서 IV·III·II / V·VI·I) · 리베로 1·2 · 교체 명단(코트 · 리베로 밖 엔트리, 코트에 넣은 사람은 목록에서 숨음). 안 낸 세트는 앞 세트 그대로, 처음엔 주전을 명단 포지션으로 자동 배치("주전으로 다시"). 낸 세트는 탭에 ✓ · "인쇄". 저장 `lineups.data.lu`(일정 담당 이상), 보기는 모두. 실시간 기록의 SNU 코트 · 교체 벤치가 이 라인업을 먼저 씀
- **9인제 대회**: 세트별 서브 타순표(팀명 · 코트 · 감독 · 코치 · 주장 · 1~15번) · 인쇄
- **교류전**: 세트별 출전(6인제 6명 · 9인제 9명) → 실시간 기록에서 그 세트 주전으로

## 6-8. 실시간 기록 (`live.js`)
- 들어가는 곳: 대회 · 교류전 페이지의 "실시간 기록"(교류전은 1경기 · 2경기 순서), 전력분석 목록의 "실시간" 탭(모든 실시간 기록, 최근 것 먼저 — 누르면 같은 화면)
- 전력분석 "실시간" 탭 위 **+ 경기 = 실시간 기록 경기**(영상 분석 Match Setup 아님): 맨 위 "일정에서 고르기"(오늘 있는 대회 · 교류전이 기본, 고르면 상대 팀 채움) 또는 "직접 입력 · 대회 / 교류전"(`ref_kind` scout · `ref_id` match / friendly — 교류전이면 세트 수 자유). **날짜**는 기록하는 날이 아니라 고른 일정의 날(교류전 날, 대회는 기간 안이면 오늘 · 아니면 첫날, 대회 기간 밖은 못 고름) · 직접 입력이면 고른 날(`live_games.date`, `lvDate`). 목록 · 경기 화면 위 · 엑셀 Date도 이 날짜. 만들면 바로 그 경기 화면

  - 공격 득점은 코트 그림에서 떨어진 자리(지키는 팀 9구역, 컴퓨터 1~9 · 0 = 모름)

  - 세트 첫 기록 전: "첫 서브" 버튼(분석 팀 · 상대) → 그 팀 화면으로, `live_games.sets[n].serve`에 저장

- **교류전은 세트 수 자유**(`lvFree` = `ref_kind` friendly): 경기 끝 없이 세트마다 21점(3세트도), 세트 칩 옆 **"+ 세트"**로 언제든 다음 세트, "N세트 21점"을 눌러 그 세트 점수 15 · 21 · 25 · 직접(`sets[n].to`, `lvTarget`). 한 교류전을 여러 경기로 나누지 않고 한 경기에 세트를 늘려 기록. 세트 번호 DB 1~30(`live_rallies`)
- **라인업 창**(버튼판 "라인업"): 두 팀 코트 6자리(앞줄 4·3·2 / 뒷줄 5·6·1, 세트 시작 자리) · 리베로 · 그 세트 시작(두 팀 로테 · 첫 서브). 2세트부터 맨 위 "이전 세트 라인업 불러오기"(앞 세트 코트 · 리베로를 칸에 채움). SNU는 명단 선수, 저장한 게 없으면 대회 라인업 → 그 세트 출전 → 주전 → 엔트리 → 부원 순으로 명단 포지션대로 자동 배치된 채로 열림. 다른 팀은 번호 + 포지션(→ `live_games.roster`). 한 팀 6칸을 다 비우면 그 팀은 번호로만 기록. 교류전 상대는 안 넣으면 이름표 기본 배치(S · OH1 · MB1 · OP · OH2 · MB2, 리베로 Li). 저장 = 세트별 `sets[n].lu[side] = {rot, slots, lib}` + `sets[n].rot · orot · serve`
- **자리 고정**(버튼판 아래 "자리 고정", 이 기기에 기억 `snuvt-lvfix`): 코트 칸이 로테 따라 돌지 않고 세트 시작 라인업 그대로 위 6칸(앞줄 4 · 3 · 2 / 뒷줄 5 · 6 · 1, 번호 + 포지션) + 아래 리베로 한 칸, 그 밑에 교체 선수. 리베로 자동 교대 없이 리베로 칸을 직접 누름. 교체하면 그 칸이 바뀜. 점수 · 로테 계산은 그대로. 컴퓨터 숫자 1~6 = 칸 순서, 7 = 리베로(`LV_FIX`)
- 번호 대신 이름표도 됨(OH1 · MB2 · Li … 교체는 OH3 · S2 …, 포지션은 이름표로) → `live_rallies.tag`
- **리베로 자동 교대**: MB가 뒷줄(5 · 6, 서브권이 없을 때는 1도)에 오면 리베로. MB가 1번에서 서브할 때는 그대로, 서브권을 잃으면 리베로, 앞줄(4)로 가면 다시 MB
- **교체**(코트가 있을 때, 팀마다): 나감 → 들어옴(벤치 선수, 또는 "새 번호" + 바로 옆 포지션 — 나간 선수 포지션이 기본, Enter = 교체, 번호를 모르면 비워 두면 그 포지션 다음 이름표) → 이 세트 코트를 바꿔 저장(로테는 그대로). 잘못 넣은 벤치 번호는 ✕로 지움(기록 · 코트에 쓰인 번호는 못 지움)
- **기록 줄마다 누가 · 언제**: 최근 기록 줄 아래 작게 "김분석 · 14:32:05"(기록한 부원 · 넣은 시각). 내 기록은 내 이름, 다른 사람 기록은 서버 함수 `live_authors(gid)`(이 경기 기록자 → 부원 이름, 같은 팀만), 모르는 기록자가 새로 보이면 한 번 더 받음(`lvBy`)
- **되돌리기**: 이 기기에서 넣은 기록만(`snuvt-lvmine`). 화면에서 먼저 빼고 지우기도 폰 대기열(`snuvt-lvq`)로 보내서 새로고침 · 인터넷 끊김에도 끝까지 지워짐
- 저장: 폰에서 만든 id로 화면에 먼저 넣고 서버로 차례대로("대기 N"), 다른 기기 기록은 Realtime으로 바로(끊기면 6초마다 다시 불러옴)
- 결과: 위는 감독용 요약 — 경기 중 감독이 먼저 보는 순서(점수 → 사이드아웃 · 브레이크 → 공격 → 범실 → 로테 · 사람)대로. ① 두 팀 비교표(사이드아웃 · 브레이크 · 공격 효율 .300 꼴 · 서브 에이스·범실 · 리시브 0~3 평균 · 블로킹 득점 · 범실, 나은 쪽 칸 초록) ② 벤치 메모(지금 우리 로테 사이드아웃, 서브 노릴 사람 = 상대 리시브 최저, 상대 주 공격수 · 주 공격, 우리 범실 가장 많은 것) ③ 공격수 · 리시브(낮은 순) · 지금 로테 · 상대 공격 분배 · 득점 자리, 그 아래 바로(버튼 없이) 두 팀 득점 구성 · 선수별 표(포지션 표시) · 공격 종류별 · 득점 자리 지도 · 세트 · 점수 상황별 · 로테별(두 팀). 이번 세트 / 경기 전체
- **로테가 어떻게 서 있는지**: 결과의 로테별 득실 표(두 팀)에서 R1~R6을 누르면 전력분석과 같은 자리 그림 창(앞줄 4·3·2 / 뒷줄 5·6·1, 포지션 · 번호 · 이름, 세터 노란 테, 뒷줄 MB는 "받을 때 리베로", 창 안 R 칩으로 넘김). 지금 고른 세트 라인업 기준(라인업이 없는 팀은 R만 글자), `lvRotView` · `lvRotBtn`
- 엑셀(경기 화면 위): 전력분석과 같은 형식(Logs는 예전 프로그램 동작 이름으로 바꿔서) · 팀별 기록지(포지션 포함) · Start Rotation · Rotation
- DB: `live_games`(ref_kind · ref_id, label, date, team(비면 SNU), opponent, roster, sets, mode = `lite`) · `live_rallies`(side, kind srv · atk · blk · dig · err · opt · ovr · cov, res, player_id · opp_no · tag, atype, shot, miss, x · y · zone, point, rot, serve). 읽기 부원, 쓰기 전력분석 담당 · 관리자

## 6-8-1. 경기 메모 (전력분석 · 실시간 기록)
- 경기마다 **자유 메모장** 하나(`scout_matches.note` · `live_games.note`). 경기 화면(전력분석 코트 · 분석 탭, 실시간 기록 화면)에서만 보임
- **넓은 화면(1100px 이상 — 노트북 · 패드 가로)**: 오른쪽 여백에 붙박이(폭 300px, 본문을 왼쪽으로 조금 밀어 코트와 안 겹침). **좁은 화면(휴대폰 · 패드 세로)**: 오른쪽 아래 "메모" 버튼(글이 있으면 "메모 ✎") → 아래에서 올라오는 창(화면 아래 절반), "닫기"
- 화면 본문(main) 밖에 있어서 기록할 때마다 화면을 다시 그려도 쓰던 글이 그대로. 쓰고 1초 쉬면(또는 칸을 벗어나면) 저절로 저장, 위에 "11/18 14:32 저장"
- 여러 기기가 같이 씀: 판 번호(`note_ver`)가 맞을 때만 저장(`match_note_save` RPC). 다른 기기가 먼저 고쳤으면 그 글에 내가 더하고 뺀 줄을 합쳐 다시 저장("다른 사람이 쓴 메모와 합쳤어요", `mnoteMerge`). 다른 기기 글은 20초마다(실시간은 Realtime으로 바로) 받아서, 내가 안 쓰는 중이면 바로 바꿈
- 보기: 부원 모두. 쓰기: 전력분석 = 부원(기록 넣는 사람), 실시간 = 실시간 기록 넣는 사람(전력분석 · 일정 담당 이상). 못 쓰는 사람은 읽기만
- 엑셀(경기 하나)에 Memo 시트(한 줄씩). 코드 `mnoteSync` · `mnoteSave` · `mnotePoll`

## 6-9. 전력분석 (`court.js`)
예전 전력분석 담당이 쓰던 PC 프로그램(VolleyballLogger) 기능을 그대로 옮기고 화면만 정리. 목록 탭: 경기 · 실시간(6-8) · 시즌(SNU 경기 누적: 명단으로 넣은 경기 + 번호로 넣은 서울대 · SNU · SNUVT 팀이 있는 경기 — 분석 팀이든 상대든. 그 쪽 기록을 우리 쪽으로 뒤집고 등번호로 부원에 붙임, `scSnuSide` · `scAsSnu`)

- **시즌 탭 구성**: 위에 팀 카드 6개(공격 효율 · 공격 성공률 · 리시브 점수 · 서브 점수 · 세트당 디그 · 세트당 블로킹, 아래에 실제 개수) → 예전 표 그대로 선수 × 경기 + 누적(지표 칩으로 바꿔 봄) → 로테이션별 득실(가장 강한 · 약한 로테 색) → 공격 종류별 · 패스에 따른 공격
  - 표기는 배구 기록 관례대로: **공격 효율 = (득점 − 범실) ÷ 시도를 .300 꼴**(퍼센트 아님, .300 이상 초록 · .100 밑 빨강, 마이너스 = 범실이 더 많음), **리시브 점수 = 0~3점 평균**(3점 3 · 2점 2 · 1점 1 · 오버 · 범실 0, 2.0 이상 초록 · 1.5 밑 빨강), **서브 점수 = 0~4점 평균**(에이스 4 · 범실 0), 디그 · 블로킹은 세트당 개수. 공격 성공률만 %
  - 셈은 경기 분석 기록지와 같음(`ctSum`). 예전 "세터 토스 분배"(쓰지 않는 토스 칸 기준이라 늘 비어 있었음)는 공격 종류별 · 패스에 따른 공격으로 바꿈 · 팀별(그 팀 경기 모아 보기, 시작 로테 · 로테별 득실 누적)
- **대회 · 교류전 나눠 보기**: 경기마다 종류(`scout_matches.kind` match · friendly, Match Setup의 "종류"). 목록 탭(경기 · 시즌 · 팀별) 위 "대회 · 교류전" 칩으로 고른 종류만(칩 옆 숫자: 경기 · 팀별 탭은 영상 경기 전부, 시즌 탭은 시즌 표에 실제로 들어가는 우리 경기만 — 다른 팀끼리 경기 · 기록 없는 경기 · 다른 시즌은 빼고, `scKindN`) — 시즌 개인 스탯 · 로테 · 팀별 상대 정리 · 전체 엑셀에 교류전이 섞이지 않음. 실시간 탭도 같은 칩으로 나눔(교류전 실시간 기록 = `ref_kind` friendly 또는 직접 입력 교류전, 그 밖은 대회, `lvKindOf` · `lvIsFr`)

## 6-13. 정산 (`money.js`, 대회 → 정산 탭) — 손으로 하던 "OO 정산 공지" 방식 그대로
- **누가**: 내역은 부원 모두 봄(사람별 금액 · 감면 · 비용 · 영수증, 투명하게). 관리(정산 만들기 · 감면 · 영수증 확인 · 보냄/받음 체크 · 공지) = 총무 · 부주장 · 관리자(주장) [`private.can('money')`]. 부원은 같이 간 정산에 내가 낸 비용 올리기 · 고치기(총무 확인 전까지)
- **정산 만들기**(+ 정산): 일정에서 고르기(지난 120일 ~ 30일 뒤 대회 · 교류전 → 이름 · 기간 · 같이 간 사람 = 엔트리, 없으면 참 투표) 또는 직접. 같이 간 사람에 졸업생도 고를 수 있음. 회비 지원(원) · 낼 돈 올림 단위(10원 · 100원 · 1,000원(기본) · 1만 원). 만들 때 "비용 올려 주세요" 공지(알림)가 저절로 올라감(끌 수 있음)
- **비용**: 종류(숙소 · 식비 · 유류비·톨비 · 물품 · 기타) · 금액 · 내용 · 낸 사람(총무 쪽은 **공금** — 동아리 돈으로 먼저 낸 것도 고름: `from_club`, 돌려받을 사람 없이 나누는 데만 들어가고 모은 돈으로 공금을 채움, 정산 공지에도 "이 중 N원은 공금으로 먼저 냈어요") · 영수증 사진(여러 장, 1600px로 줄여 비공개 버킷 `receipts/{팀}/{정산}/{올린 사람}/…`). **유류비 · 톨비는 차마다 달라서 운전자가 대략 직접 적음**(계산 안 함, 영수증 없어도 됨 → "영수증 없음(직접 적음)"). 총무가 "확인"을 누르면 부원은 더 못 고침
- **사람마다 조정**(이름 누르기, 그때그때): 운전(켜면 전부 면제, 바꿀 수 있음) · 종류별 면제 · **정액**(늦참 · 매니저처럼 "이 사람은 1만 원만") · 금액 감면 · 이번 정산에서 빼기
- **계산**(`stCalc`): 종류마다 면제 아닌 사람끼리 똑같이 → 정액 · 감면으로 생긴 차액은 아무 조정 없는 나머지 인원이 나눠 냄 → 회비 지원은 사람마다 똑같이 뺌 → 올림 단위로 올림. 정산 = 낸 돈 − 낼 돈: 받음(총무가 보내 줌) / 보냄(총무에게). 사람마다 "확인"(끝) 체크
  - 예: 박계조배 17명 — 운전자 4명(전부 면제, 유류비 · 톨비 6만 원씩 직접 적음) · 늦참 · 매니저 정액 1만 원 · 숙소 15만 · 식비 7만 → 나머지 11명 4만 원씩, 운전자는 6만 원씩 받음
- **정산 공지**: 예전 카톡 공지 모양 그대로 글을 만들어 줌(참가 인원 · 총 비용과 종류별 · ⭐️금액(같은 금액끼리 묶음) · 먼저 낸 비용이 있는 분(낸 돈 − 낼 돈) · ⭐️ 계좌). 계좌는 그 칸에 총무가 직접 적고(앱에 따로 저장 안 함, 안 적으면 한 번 물어봄) 고쳐서 홈 공지로 올림(알림 · 맨 위 고정) 또는 복사. **정산 끝내기**하면 비용을 더 못 올림(다시 열기 가능)

## 6-10. 교내 대회
- '대회' 위 탭(대회 · 교류전 · 교내 대회)에서 바로 들어감. 대회가 여럿이면 위 칩으로 고름. 다른 곳의 바로가기(홈 달력 · 일정)는 그대로
- 1학기 총장배, 2학기 종합체육대회. 공지·참가 신청은 스포츠진흥원 네이버 카페(대회마다 글 주소 저장)
- 대회 기간에는 남·여 정규 훈련 대신 "종합체육대회 주"(달력·홈에 표시, 피지컬은 고르는 날)
- 가능일: 부원(남녀)이 날마다 참/불참(불참은 사유 · 메모, 대회·훈련 투표와 같은 창) → 일정 담당(부주장)·관리자가 경기마다 심판 배정
- 심판 칸은 남녀 명단(서버 함수 `cup_people()`, 이름·팀만)에서 고르거나 직접 입력. 그날 가능한 사람을 누르면 빈 칸에 들어가고, 숫자는 이번 대회에 맡은 횟수
- 대진표: 자리 이름 "A1위"(조 경기가 다 끝나면) · "6강 1경기 승자/패자"(그 경기 점수가 들어가면)가 팀으로 바뀌고, 이 이름으로 선이 이어짐. 점수는 "2-1"처럼 세트
- 경기 목록: 시간 · 경기 이름 · 점수 / 팀 · 버튼(심판 · 사진 · 기록 · 수정). 심판은 "심판" 버튼을 눌러야 펼쳐짐(내가 맡은 경기는 버튼에 "내 주심" 등으로 표시)
- 경기 수정 창: 예선 경기는 A·B 팀을 고르고, 본선 경기는 자리 이름(A1위 · B선택 · 6강 1경기 승자)만 — 팀 선택 칸 없음, 팀은 결과대로 저절로 들어감
- 화면은 경기 · 가능일 · 조편성 · 대진표 탭으로 나눔
- 자동 맞춤(`syncCup`): 팀 추가·수정·삭제, 조 추첨, 대회 수정(본선 진출 조 n위) 때 조마다 풀리그 경기와 본선 대진을 다시 계산. 같은 경기는 시간·심판·점수를 그대로 두고, 빠진 경기는 추가(날짜는 대회 첫날/마지막 날, 시간은 비워 둠), 필요 없어진 경기는 점수가 없을 때만 삭제
- 본선: 조 n위까지 자리 수에 맞춰 부전승(1위 먼저)을 두고 첫 경기 같은 조끼리는 피함. 3개 조 · 2위까지는 우리 대회 방식(A1위·C1위 부전승, B선택). 2개 조 → 4강(A1–B2, B1–A2), 4개 조 → 8강. 본선 9팀 이상은 직접 입력
- 경기 기록: 경기마다 "기록" → 세트별 점수(3세트는 15점) 또는 기권. 세트 수·승자는 자동 계산(`cup_score()`), 그 경기 주심·부심·기록심과 관리자·주장·부주장만 입력
- 기권: 기권 팀은 조 순위에서 빠지고(그 팀과 한 경기도 순위 계산에서 뺌) "A1위" 같은 본선 자리는 그 아래 순위 팀이 올라감
- 자리 선택("B선택", `cups.picks`): B조 경기가 끝나면 1위가 들어갈 경기를 관리자가 골라 줌(대진표 탭, 대진표 아래 한 줄). 1위는 고른 경기, 2위는 남은 자리
- 본선 기권(`cup_teams.ko_out`): 예선 기록·순위는 그대로 두고 본선 자리만 다음 순위 팀이 진출 (예: 2026 종체 화학부 배구부 → CSDP)
- 팀 사진: 경기마다 "사진" → 팀별로 휴대폰 사진 올리기(부원 누구나, 1600px로 줄여 비공개 버킷 `cup-photos`, 표 `cup_photos`). 결과 글에는 경기마다 1장: 이긴 팀 먼저, 그다음 아직 사진이 안 들어간 팀(같은 팀은 한 번만). 붙여 넣을 때 사진이 안 따라오면 아래 사진을 저장해서 올림
