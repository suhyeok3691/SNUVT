# SNUVT — 서울대 배구부 관리

남자부·여자부가 같이 쓰는 배구부 앱이에요. 화면은 정적 파일(HTML·JS), 로그인·데이터는 Supabase, 배포는 Vercel(GitHub `main`에 올리면 자동)이에요.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 틀과 디자인 (CSS) |
| `app.js` | 화면 동작: 홈 · 훈련(계획·영상·노트) · 피지컬 · 일정 · 관리 · 설정 |
| `program.js` | 피지컬 프로그램 엔진: 1년 일정 → 날마다 운동, 포지션·근력·부상 규칙, 팀별 요일(`TEAM`) |
| `library.js` | 운동 박스 목록, 훈련 드릴 목록, 훈련 계획 기본 틀 |
| `guide.js` | 운동 이름을 누르면 나오는 하는 법 |
| `config.js` | Supabase 주소와 공개 키 (service_role 키는 절대 넣지 않기) |
| `sw.js`, `manifest.webmanifest` | 휴대폰 앱처럼 설치 · 오프라인 · 알림 |
| `supabase/schema.sql` | 데이터베이스 구조와 바뀐 기록 |

## 팀

- 가입할 때 남자부·여자부를 골라요. 다른 팀 데이터는 데이터베이스 규칙(RLS)으로 막혀서 보이지도, 고쳐지지도 않아요.
- 팀마다 다른 것: 정규 훈련 요일(남자부 1학기 월·목 / 2학기 수·금, 여자부는 반대), 네트 높이(243 / 224cm), 일정·공지·영상·훈련 계획.
- 여자부 첫 관리자는 그 사람이 여자부로 가입한 뒤 SQL Editor에서 정해요:
  `update public.profiles set role = 'coach' where email = '이메일' and team_id = 'women';`
  그다음부터는 앱의 관리 → 부원에서 직책을 정하면 돼요.

## 직책 (팀마다)

| 직책 | 할 수 있는 것 |
| --- | --- |
| 관리자 · 주장 | 전부 |
| 부주장 | 일정 · 교류전 · 엔트리 · 공지 · 명단 · 영상 · 훈련 관리 |
| 훈련부장 | 훈련 계획 · 훈련 관리(정규 훈련 시간·없는 날·자율 훈련·불참 확인) |
| 총무 | 공지 · 명단 |
| 피지컬 코치 | 피지컬 프로그램 편집 · 측정 수정 · 리포트 |
| 영상 담당 | 영상 추가·수정 |
| 부원 · 군 복무 | 내 운동·기록, 일정, 자율 훈련 투표, 불참 |

## 고칠 때

1. 파일을 고치고 `index.html`의 `?v=` 숫자를 올려요 (휴대폰 캐시 갱신).
2. `main`에 push 하면 1분 안에 배포돼요.
3. 데이터베이스를 바꾸면 `supabase/schema.sql` 끝에 무엇을 바꿨는지 적어 둬요.
